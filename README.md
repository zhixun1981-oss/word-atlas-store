## 这是做什么的？

背单词最大的问题是：**记住了拼写，考试时不会用；今天背了，下周忘光。**

拾词把"剑桥考纲词表"变成一本**看得见的单词画册 + AI 陪练**：每个词都配原创插画，图像记忆让大脑更容易记住；考纲词表按 KET/PET 官方考点组织，**背的就是考试要考的**；AI 还能随时陪你练口语、出题、造句——像请了一个全天候的单词私教。

## 三大亮点

### 1. 一词一画，看图就记住
- 7,000+ 词条（A1–C2），**每条配原创插画**，视觉记忆符合大脑记词规律
